# ZapBot — versiones publicadas

Acá solo se publican los **APK** de ZapBot y el archivo `update.json` que la app
consulta para saber si hay una versión nueva. El código fuente es privado.

- Última versión: ver [Releases](../../releases/latest).
- `update.json`: lo lee la app; no se edita a mano (lo actualiza `scripts/publicar.sh`).
